# Python Data Scraper & Visualizer

A simple and powerful Python script that prompts the user for a website URL, extracts web data using BeautifulSoup, processes the information with Pandas, and generates clean visual data plots using Seaborn and Matplotlib.

## Features
- **Interactive Input:** Uses Python's built-in `input()` function to let you specify any target URL dynamically.
- **Web Scraping:** Leverages BeautifulSoup and Requests to parse and extract text metrics from web pages.
- **Data Processing:** Automatically structures raw scraped data into a structured Pandas DataFrame.
- **Data Visualization:** Plots character counts and structural insights using Seaborn and Matplotlib.
